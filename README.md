# Hassy Natural

Phone-first installable PWA for the Hassy Natural colour treatment.

- Camera capture through the browser camera picker
- Bulk photo import
- Natural colour processing on-device
- Before/after comparison and intensity control
- JPEG export
- Installable on iPhone from Safari

This is an independent Hasselblad-inspired treatment and does not contain Hasselblad proprietary HNCS data.
